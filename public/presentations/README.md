# Presentation PDFs

Add your presentation PDF files here.

## PSC9 Pitch Deck

To use your own PDF for the PSC9 Pitch Deck:

1. Place your PDF file in this folder and name it `psc9-pitch-deck.pdf`
2. The presentation viewer will automatically load it when you visit `/presentation/psc9`
3. All pages in your PDF will be displayed with navigation controls

### To upload your PDF:

- Simply place your PDF file at: `public/presentations/psc9-pitch-deck.pdf`
- The viewer will automatically detect the number of pages
- Use Previous/Next buttons or click page numbers to navigate

### If no PDF exists:

The fallback will display the built-in 12-slide presentation created with React components.
